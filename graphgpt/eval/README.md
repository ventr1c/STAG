# GraphGPT Evaluation Utilities

This directory contains optional GraphGPT-style evaluation utilities. They are
not required for the main STAG attack and evaluation commands described in the
top-level `README.md`.

For reproducing the paper experiments, use the GraphGPT training and backdoor
evaluation commands in the top-level `README.md`. Any additional model or API
paths used by these utilities should be supplied through local environment
variables or command-line arguments.
